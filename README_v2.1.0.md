# DNS Phishing Guard v2.1.0 — Bản Kỹ thuật

1. Mở `edge://extensions` hoặc `chrome://extensions`.
2. Bật Chế độ nhà phát triển.
3. Tắt phiên bản DNS Phishing Guard khác.
4. Chọn Tải tiện ích đã giải nén và chọn thư mục bản Kỹ thuật.
5. Tải lại các tab đã mở trước khi cài.

Bản này hiển thị đầy đủ feature breakdown, URL ML, RDAP, redirect, Content Safety, lịch sử, thống kê và công cụ xuất chẩn đoán JSON.
